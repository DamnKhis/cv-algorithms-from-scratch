# 👁️ Computer Vision Algorithms from Scratch (NumPy)

Низкоуровневая реализация фундаментальных алгоритмов компьютерного зрения и цифровой обработки изображений на чистом **NumPy** без использования готовых высокоуровневых функций OpenCV.

Проект демонстрирует математические основы пространственной фильтрации и параметрического анализа геометрических примитивов. OpenCV используется исключительно для операций ввода-вывода (чтение/запись файлов) и предварительного выделения границ (Canny Edge Detector).

---

## 📌 Реализованные модули

### 1. Параметрическое преобразование Хафа (`hough_transform.py`)
Собственная реализация алгоритмов детекции аналитических кривых через аккумуляторы в пространстве параметров:

* **Детекция прямых линий (Hough Lines):**
  * Переход в нормальное полярное пространство параметров:  
    $$\rho = x \cos(\theta) + y \sin(\theta)$$
  * Дискретизация угла $\theta \in [0, 180^\circ)$ и расстояния $\rho \in [-\text{diag}, \text{diag}]$.
  * **Оптимизация:** аккумуляция голосов векторизована через `np.nonzero` и `np.add.at` без медленных вложенных циклов по пикселям изображения.
  * **Non-Maximum Suppression (NMS):** алгоритм подавления немаксимумов для фильтрации дублирующихся близких линий по евклидову расстоянию и углу.

* **Детекция окружностей (Hough Circles):**
  * Параметрическое пространство центров окружностей $(a, b)$ при заданном радиусе $r$:  
    $$a = x - r \cos(\theta), \quad b = y - r \sin(\theta)$$
  * Итеративный поиск по сетке радиусов $[R_{\min}, R_{\max}]$ с шагом дискретизации углов $15^\circ$.
  * Фильтрация пересекающихся фантомных окружностей на базе пространственной кластеризации.
  * **Сравнение:** в скрипт встроена визуальная верификация собственного алгоритма против эталонной реализации `cv2.HoughCircles`.

---

### 2. Медианный пространственный фильтр (`median_filter.py`)
Реализация нелинейного фильтра для эффективного подавления импульсного шума («соль и перец») с сохранением резких перепадов яркости (границ):

* Поддержка произвольного нечетного размера ядра скользящего окна ($k \times k$).
* Корректная обработка граничных эффектов через зеркальный паддинг (`cv2.BORDER_REFLECT`), исключающий появление темных рамок по краям кадра.
* Универсальность: фильтрация как монохромных 2D-изображений (Grayscale), так и полноцветных 3D RGB-матриц с сохранением цветовых каналов (`np.median(..., axis=(0, 1))`).

## 🔬 Математика и оптимизация

При реализации алгоритмов на Python ключевой проблемой является производительность. В проекте применены векторизованные подходы библиотеки **NumPy**:

1. **`np.nonzero(edge_img)`:** мгновенное извлечение координат только активных граничных пикселей, снижающее число итераций на порядки.
2. **`np.add.at(accumulator, ...)`:** in-place аккумуляция голосов в двумерные матрицы без создания промежуточных копий массивов.
3. **Векторизованная тригонометрия:** предварительный расчет таблиц синусов и косинусов для фиксированной сетки углов.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/DamnKhis/cv-algorithms-from-scratch.git
cd cv-algorithms-from-scratch
```

### 2. Установка зависимостей
```bash
pip install numpy opencv-python
```

### 3. Запуск детектора Хафа
Положите тестовое изображение `small.jpg` в корень папки и запустите:
```bash
python hough_transform.py
```
Скрипт откроет 3 окна: бинарную карту границ, результат работы кастомного алгоритма и результат функции OpenCV для прямого сравнения.

### 4. Запуск медианного фильтра
```bash
python median_filter.py
```
Программа интерактивно запросит путь к картинке и желаемый размер ядра (например, `3`, `5` или `7`).
